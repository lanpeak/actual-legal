# Actual Budget – Legal

Privacy Policy and Terms of Use for a private, non-commercial, self-hosted [Actual Budget](https://actualbudget.org/) installation using [Enable Banking](https://enablebanking.com/) for bank synchronization.

Enable Banking requires publicly accessible Privacy Policy and Terms of Use URLs when registering a Production application. This repository publishes those documents via GitHub Pages.

- Privacy Policy: <https://lanpeak.github.io/actual-legal/privacy-policy/>
- Terms of Use: <https://lanpeak.github.io/actual-legal/terms-of-use/>
